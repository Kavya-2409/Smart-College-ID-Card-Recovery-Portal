# Smart ID Recovery Portal

A web-based application developed to help students recover lost college ID cards efficiently. The system allows users to report lost or found IDs, search for matching records, and track the recovery status through a simple and user-friendly interface.

## 🚀 Features

- Report lost and found college ID cards
- Search by Roll Number or Student Name
- Track ID recovery status
- User authentication and session management
- Dashboard for managing reports
- Responsive and easy-to-use interface

## 🛠️ Technologies Used

- Java
- JSP (Java Server Pages)
- HTML5
- CSS3
- MySQL
- Apache Tomcat

## ⚙️ Prerequisites

- JDK 8 or above
- Apache Tomcat 9+
- MySQL Server
- Eclipse IDE (Enterprise Edition) or IntelliJ IDEA

## 🔧 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/Smart-ID-Recovery-Portal.git
```

2. Import the project into Eclipse/IntelliJ.

3. Create the MySQL database.

4. Update the database credentials in the project.

5. Deploy the project on Apache Tomcat.

6. Open your browser and visit:

```
http://localhost:8080/Smart-ID-Recovery-Portal/
```

## 💡 How It Works

1. Students report a lost or found ID card.
2. The system stores the information securely.
3. Users search using Roll Number or Student Name.
4. Matching records are displayed.
5. Students can track the recovery status of their ID cards.
